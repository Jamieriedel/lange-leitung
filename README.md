# Lange Leitung

Gemeinsame freie Zeiten für die Runde finden – Kalender als .ics-Datei rein, gemeinsame Lücke raus.

**Live:** https://jamieriedel.github.io/lange-leitung/

- Läuft komplett im Browser, kein Server, kein Login
- Geteilt werden nur Belegt-Zeiten, keine Termindetails
- „Runde als Link teilen" packt den Stand der Gruppe in den Link selbst
