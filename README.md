# Friends-App

Gemeinsame freie Zeiten für deine Gruppe finden – plus Wanna-dos, Umfragen und Kosten-Splitter.

**Live:** https://jamieriedel.github.io/lange-leitung/

- Gruppen mit Zugangscode, Live-Speicher pro Gruppe, kein Login
- Kalender als .ics-Link oder Datei – geteilt werden nur Belegt-Zeiten
- Termin finden · Wanna-dos (mit ❤️-Abstimmung) · Umfragen · Kosten teilen
- Läuft auf GitHub Pages + Cloudflare Worker (iCal-Proxy & Gruppen-Speicher)
